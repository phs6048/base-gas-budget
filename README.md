# Base Gas Desk

지갑을 연결하지 않고 Base 메인넷의 가스비·배포 예산을 계산하는 한국어 웹 도구입니다.
AI의 도움을 받아 만들었습니다. Base 또는 Coinbase의 공식 서비스가 아닙니다.

## 기능

- 예산과 예비 잔액을 기준으로 목표 배포 횟수의 비용·부족액·남는 잔액 계산
- L2 실행 비용, L1 데이터 수수료, 운영 수수료, 수수료 여유 비율, 전송 ETH 포함
- 버튼을 눌러 Base 공개 RPC의 gas 가격 조회. 체인 ID 8453 확인
- JSON 형식으로 입력값·계산 결과·gas 가격 출처 저장
- 모든 ETH 계산에 BigInt/wei 정수 사용. 수수료 여유분은 1 wei 단위로 올림
- 설치 및 빌드 의존성 없음. 반응형 레이아웃, 한국어, 키보드 접근 지원

## 실행

Python 3가 있다면 저장소 폴더에서:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8080 을 엽니다. ES 모듈을 사용하므로 파일을 더블클릭하는 방식 대신 HTTP 서버로 실행하세요.
`index.html`, `style.css`, `app.js`, `calculator.js` 네 파일을 일반 정적 호스팅에 올릴 수도 있습니다.

## 사용법

1. 총 예산과 유지할 잔액을 입력합니다.
2. Remix 또는 지갑에서 확인한 gas 사용량과 gas 가격을 입력합니다.
3. L1 데이터 수수료와 운영 수수료를 별도로 입력합니다.
4. 수수료 여유 비율과 배포당 전송 금액을 설정합니다.
5. 목표 횟수를 입력하고 계산 결과를 확인합니다.

처음 표시되는 모든 값은 예시입니다. RPC 조회는 gas 가격만 바꾸며,
컨트랙트 bytecode를 분석하거나 L1·운영 수수료를 자동 추정하지 않습니다.
RPC는 공개 서비스라 요청 제한·CORS·네트워크 오류로 실패할 수 있습니다.
조회가 실패하면 기존 입력값이 유지되고 실패 상태가 표시됩니다.
조회된 가격도 해당 시점의 제안값일 뿐 이후 수수료를 보장하지 않습니다.
gas 사용량과 gas limit은 다를 수 있으며, 지갑은 최대 수수료를 감당할 잔액을 요구할 수 있습니다.
실제 전송 가능 여부와 최종 수수료는 지갑에서 다시 확인하세요.

## 계산

```text
L2 실행 비용 = gas 사용량 × gas 가격(wei)
기본 수수료 = L2 실행 비용 + L1 수수료 + 운영 수수료
여유 포함 수수료 = ceil(기본 수수료 × (1 + 여유 비율 / 100))
건당 금액 = 여유 포함 수수료 + 배포 시 전송 ETH
사용 가능 예산 = 총 예산 - 예비 잔액
가능 횟수 = floor(사용 가능 예산 / 건당 금액)
```

동일한 비용이 모든 배포에 적용된다는 시나리오 계산입니다.
Base 수수료 구성 참고: https://docs.base.org/specifications/transactions/network-fees

## 검증

Node.js 20 이상에서 의존성 설치 없이 실행합니다.

```sh
node --test
```

wei 변환, 올림, 예산 경계, L1·운영 수수료·전송 금액 포함 여부, 잘못된 입력을 검사합니다.

## 개인정보와 네트워크

지갑 주소·개인키·시드 문구를 입력받지 않고 지갑에 연결하지 않습니다.
분석 도구, 쿠키, CDN, 외부 폰트, 서버 저장 기능을 사용하지 않습니다.
사용자가 조회 버튼을 누르면 브라우저에서 `https://mainnet.base.org`로
`eth_chainId`, `eth_gasPrice` 두 종류의 읽기 요청만 보냅니다. 예산 등 입력값은 전송하지 않습니다.
RPC 제공자는 일반 HTTP 연결 정보(IP 등)를 볼 수 있습니다.
JSON 내보내기는 사용자의 기기에 파일을 저장합니다.
트랜잭션 생성·서명·배포·전송 기능은 없습니다. 외부 서비스의 롤이나 보상을 보장하지 않습니다.
